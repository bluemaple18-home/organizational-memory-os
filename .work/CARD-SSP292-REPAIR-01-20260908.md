## Findings 與處置

### SSP292-RV-001（P0）— cross-owner intersection 可為假 ref

- 事實：evaluator 只驗 `entry["memory_ref"] == memory["memory_ref"]`，未驗 `intersection_ref` 存在。跨 owner memory 可在無真正 intersection ref 下進 MemoryContextPack。
- 修：對每個跨 owner selected memory，matching entry 必須存在且 `present?(entry["intersection_ref"])`；鎖 entry shape（`memory_ref` + `intersection_ref` 兩鍵）。補 `CTXPACK_NEG_CROSS_OWNER_EMPTY_INTERSECTION_REF` → `CROSS_OWNER_WITHOUT_INTERSECTION`。

### SSP292-RV-002（P0）— permission decision 可只有 boolean、無 decision ref

- 事實：required-pack 檢查只有 `!pack.key?(field)`；`permission_decision_ref: null` + `permission_decision_before_selection: true` 仍過。permission-before-selection 退化成自我聲明 boolean。
- 修：`pack_id` / `request_ref` / `permission_decision_ref` 用 `present?`；`permission_decision_covered_memory_refs` 必須是 Array。補 `CTXPACK_NEG_NULL_DECISION_REF` → `CONTEXT_PACK_MISSING_FIELD`。

### SSP292-RV-003（P1）— `NOT_APPLICABLE_FILTERED` 無 enforcement

- 事實：evaluator 只驗 stale 與 budget；有不適用內容被過濾卻不告知仍 allow。
- 修：pack 新增 machine-readable `not_applicable_filtered_count`（列入 `pack_required_fields`）；`> 0` 時 `omitted_or_gap_notice` 必須含 `reason: NOT_APPLICABLE_FILTERED` → 否則 `NOT_APPLICABLE_WITHOUT_NOTICE`。補 exact-code negative。

### SSP292-RV-004（P1）— `UNRESTRICTED_GLOBAL_SEARCH` 未擋

- 事實：`forbidden` exact-set 含兩條，evaluator 只擋 `GLOBAL_THEN_PROMPT_GUARD`。
- 修：`search_strategy` 對映表 → `GLOBAL_THEN_PROMPT_GUARD` → `SEARCH_ALL_THEN_PROMPT_GUARD`、`UNRESTRICTED_GLOBAL_SEARCH` → `UNRESTRICTED_GLOBAL_SEARCH`，兩者皆 fail closed。補單一 mutation fixture。
