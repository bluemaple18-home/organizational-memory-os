## 契約重點（對應 Acceptance）

- **只編排既有能力**：`orchestration.allowed_capabilities` 鎖定 `[HOOK, SKILL, LOOP]`；step
  `capability ∉` 該集合 → `HARNESS_UNKNOWN_CAPABILITY`。
- **順序單 agent + 有據 fan-out**：`execution_mode` 必須 `SEQUENTIAL_SINGLE_AGENT`
  （run 非此值 → `HARNESS_NOT_SEQUENTIAL`）；step `fan_out: true` 但缺 `measured_gap_ref`（URN）
  → `HARNESS_UNJUSTIFIED_FANOUT`。
- **不建第二套 runtime**：`builds_registry` / `builds_fsm` / `builds_database` /
  `builds_canonical_writer` 任一 `true` → `HARNESS_SECOND_RUNTIME`。
- **每步可追溯**：step 缺 `{step, capability, input_ref, output_ref, timeout_seconds, error,
  receipt_ref}` 任一 key 或 `timeout_seconds` 非正整數 → `HARNESS_STEP_NOT_TRACEABLE`；
  `input_ref` / `output_ref` / `receipt_ref` 非 `urn:omos:` URN → `HARNESS_STEP_REF_NOT_URN`。
- **單步失敗 loud 且標記**：`outcome ∉ {COMPLETED, STEP_FAILED}` → `HARNESS_INVALID_OUTCOME`；
  某步 `error` 非空但 `outcome == COMPLETED` → `HARNESS_SILENT_STEP_FAILURE`；
  `outcome == STEP_FAILED` 但 `failed_step` 不在 steps → `HARNESS_STEP_FAILURE_UNMARKED`。
- **authority floor**：`performs_memory_acceptance` / `writes_company_knowledge` /
  `makes_permission_decisions` 皆 `false`；run 帶 `personal_acceptance_ref` /
  `permission_decision_ref` 等 5 個 forbidden 欄位或宣稱越權 → `HARNESS_EXCEEDS_AUTHORITY`。
- **不依賴常駐服務**：`requires_always_on_service: true` → `HARNESS_REQUIRES_ALWAYS_ON`。
- **可移除 + 回退**：`disable_and_rollback` = `removable: true` + `fallback:
  DIRECT_SKILL_INVOCATION` + `side_effects[]` 逐副作用列 `{name, teardown, failure_state}`
  （step_queue / capability_bindings / partial_run_record 三個，非 fixed-diff）；缺 →
  `HARNESS_ROLLBACK_MISSING_FIELD` / `HARNESS_ROLLBACK_SIDE_EFFECT_UNSPECIFIED`。
- **fail-loud**：`authority.error_behavior: FAIL_LOUD`（與 boundary `error_behavior_enum` 交叉鎖）；
  run 有 `error` 但 `ok != false` → `FAIL_SILENT`。
- **cross_reference**：`must_match` 四 pointer 字串 exact，引用目標
  （hook / skill / loop `schema.schema_id`、boundary `error_behavior_enum`）存在且相符。
- **runtime_independence: true**：fixtures 無 runtime-specific 欄位。
