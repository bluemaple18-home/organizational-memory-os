## 契約重點（對應 Acceptance）

- **只擷取允許事件**：`capture_contract.allowed_events` = `ai-task-card-record.lifecycle_event_to_status`
  的 key 子集（`start/block/unblock/submit_review/complete/cancel`）；validator 斷言子集關係；
  batch 含不允許事件 → `HOOK_EVENT_NOT_ALLOWED`。
- **reference-only**：envelope 五欄 `task_ref/event/occurred_at/event_key/evidence_refs`；
  `task_ref` 與 `evidence_refs` 必須是 `urn:omos:` URN；內嵌 `inline_content`／`task_body`
  → `HOOK_EVENT_INLINE_CONTENT`。
- **冪等**：以 `event_key` 去重；emitted 批次必須等於去重後事件序列，否則
  `HOOK_DUPLICATE_NOT_IDEMPOTENT`。
- **ordering / transition**：去重後第一個事件非 `start` → `HOOK_BATCH_MUST_START`；
  序列違反 `ai-task-card-record.allowed_status_transitions` → `HOOK_ILLEGAL_TRANSITION`。
- **失敗隔離**：`failure_isolation.on_error` 鎖定 `ISOLATE_FROM_HOST_TASK`，`forbidden`
  含 `PROPAGATE/RAISE_INTO_HOST/BLOCK_HOST_TASK`；capture 回報 `host_task_impact: BLOCKED`
  → `HOOK_FAILURE_BLOCKS_HOST_TASK`。
- **authority**：`reads_task_content/performs_memory_acceptance/writes_company_knowledge`
  全 `false`；emitted 批次帶 `personal_acceptance_ref` 等 4 個 forbidden 欄位或宣稱越權
  → `HOOK_EXCEEDS_AUTHORITY`。
- **output = Skill input**：emitted `lifecycle_events` 空 → `HOOK_OUTPUT_NOT_SKILL_INPUT`
  （非空且過 ordering/transition 即滿足 `ai-work-record-skill` `input_contract.lifecycle_events_rule`）。
- **停用回退**：`disable_and_rollback` = `disable_switch: true` + `disabled_behavior: EMIT_NOTHING`
  + `fallback: MANUAL_SKILL_INVOCATION` + `side_effects[]` 逐副作用列 `{name, teardown, failure_state}`
  （event_queue／registered_lifecycle_handler／partial_batch 三個，非 fixed-diff）；停用狀態下
  仍發非空批次 → `HOOK_DISABLED_STILL_EMITTING`；side_effect 缺欄位 →
  `HOOK_ROLLBACK_SIDE_EFFECT_UNSPECIFIED`；缺 disable_switch → `HOOK_ROLLBACK_MISSING_FIELD`。
- **fail-loud**：`authority.error_behavior: FAIL_LOUD`（與 boundary `error_behavior_enum` 交叉鎖）；
  capture 有 `error` 但 `ok != false` → `FAIL_SILENT`。
- **cross_reference**：`must_match` 四個 pointer 字串 exact，且引用目標
  （`lifecycle_event_to_status`／`allowed_status_transitions`／skill `lifecycle_events_rule`／
  boundary `error_behavior_enum`）存在且非空。
- **runtime_independence: true**：fixtures 不含任何 runtime-specific 欄位。
