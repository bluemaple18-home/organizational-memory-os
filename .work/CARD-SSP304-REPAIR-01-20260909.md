   `EXPECTED_SUPPORTED_VERSIONS`（= spec `compatibility.supported_hermes_versions`,已有結構斷言鎖）。
   evaluator 不再讀 `run["supported_hermes_versions"]`。yaml `compatibility` 補 `version_authority`

   yaml `mapping_run` 補 `mapping_binding_rule`；`error_contract` 補該碼。新增負例
   `HERMES_NEG_MAPPING_NOT_DECLARED`（table `started → start`,run `started → complete`）。

   present?(error) && ok == false`。yaml `compatibility.rule` 補述；`error_contract` 補該碼。
   新增負例 `HERMES_NEG_FAKE_FAIL_LOUD`（`INCOMPATIBLE_FAIL_LOUD` 但無 `error`、`ok:true`）。
4. **F-04**：event_map 迴圈加:entry `hermes_event` 必須非空字串;跨 entry 唯一（`seen_events`
   去重）。malformed → 新 `HERMES_EVENT_MAP_MALFORMED`（取代原本此路徑的 `HERMES_MAP_TARGET_UNKNOWN`）。
   yaml `event_mapping.rule` 補述；`error_contract` 補該碼。新增負例
   `HERMES_NEG_EVENT_MAP_NO_KEY`（entry 缺 `hermes_event`）與 `HERMES_NEG_EVENT_MAP_DUPLICATE`
