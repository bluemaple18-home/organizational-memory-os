## 定點修法（同 branch `cc/ssp302-loop-closeout`,原 review SHA `165209195` immutable）

1. **F-01**：run record 新增可驗時間量 `elapsed_seconds`（非負整數）。
   - bounded 檢查改為 `positive_integer?(max_iterations) && positive_integer?(timeout_seconds)
     && non_negative_integer?(elapsed_seconds)` → 缺任一 `LOOP_UNBOUNDED`。
   - 新 `LOOP_OVER_TIMEOUT`：`elapsed_seconds > timeout_seconds` 且 run 不是以
     `outcome=FAILED_LOUD` + `terminal_condition=TIMEOUT` 收尾 → 拒。
   - yaml `termination` 補 `elapsed_seconds_rule` / `timeout_enforcement_rule`；`error_contract` 補
     `LOOP_OVER_TIMEOUT`。新增負例 `LOOP_NEG_NO_ELAPSED` → `LOOP_UNBOUNDED`、
     `LOOP_NEG_OVER_TIMEOUT`（elapsed 500 > timeout 300,outcome CLOSED）→ `LOOP_OVER_TIMEOUT`；
     新增正例 `LOOP_POS_TIMEOUT_TERMINATED`（elapsed 305 > 300,但 `FAILED_LOUD` + `TIMEOUT`）→ allow。
2. **F-02**：mandatory-stop gap 改為 **逐輪** 檢查（`each_with_index`）。第一個帶
   `requires_human_decision:true` 的 iteration 必須是最後一輪且 `outcome=BLOCKED` + `blocker_ref`
   （否則 `LOOP_SKIPPED_HUMAN_DECISION`）；第一個帶非人類 `auto_fixable:false` 的 iteration 必須
   是最後一輪且 `outcome=FAILED_LOUD`（否則 `LOOP_UNFIXABLE_NOT_LOUD`）。yaml `run_record` 補
   `mandatory_stop_rule`。新增負例 `LOOP_NEG_HUMAN_GAP_MIDWAY`（iter1 human gap、iter2 清掉、
   `outcome=BLOCKED`）與 `LOOP_NEG_UNFIXABLE_MIDWAY`（iter1 unfixable、iter2 清掉、
   `outcome=FAILED_LOUD`）—— 只有「gap 不在最後一輪」這條會抓到。
3. **F-03**：每個 iteration fail-closed 驗 `iteration_fields` 三欄齊備且
   `filled_fields` / `remaining_gaps` 皆為 `Array` → 否則新 `LOOP_MALFORMED_ITERATION`。
   yaml `run_record` 補 `iteration_shape_rule`；`error_contract` 補該碼。新增負例
   `LOOP_NEG_MALFORMED_ITERATION`（iteration 缺 `remaining_gaps`）。
4. **F-04（P3）→ backlog**：reviewer 判定為 spec 定義問題且不阻塞。記入

   `ALL_REQUIRED_PRESENT` 才能 `CLOSED`,`MAX_ITERATIONS_REACHED` 需要一個非成功 outcome。」
