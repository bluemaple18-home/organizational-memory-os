# 禁止重刻政策

## 核心原則

> 能吸成熟開源的演算法、failure handling、tests、adapter pattern，就不要重新發明。

> Borrow the engineering, preserve the architecture.

## Prior-Art-First Gate

```text
Problem
→ Existing Knowledge SaaS Seam
→ Open-source Prior Art Scan
→ Semantic / Authority Diff
→ Reuse Tests / Failure Cases
→ Reuse Algorithm
→ Adapt Implementation
→ 必要時才 Dependency
→ 最後才 Custom Implementation
```

## Reuse 類型

- `DIRECT_REUSE`：授權相容、邊界乾淨，可直接採 package/code
- `ADAPT`：拿成熟 implementation，包 adapter 對接本產品 contract
- `ABSORB`：只吸演算法、tests、failure handling、protocol pattern
- `REFERENCE_ONLY`：授權或 authority 不適合，只能研究
- `CUSTOM_DELTA`：只寫本產品獨有 semantics
- `SHOULD_NOT_ADOPT`：明確禁止搬進來

## 優先吸收順序

1. failure cases
2. regression tests
3. algorithms
4. protocol patterns
5. adapter implementation
6. proven operational handling

慎重吸：dependencies、storage implementation、schemas。

禁止直接吸：canonical authority、identity model、permission authority、lifecycle/FSM、task model、memory truth、knowledge truth、mutable runtime DB 作 canonical DB。

## 每張重要施工卡必填

```text
Prior Art
Reuse Candidate
Absorb
Do Not Absorb
License
Existing Seam
Why Custom Code Is Still Needed
```

如果 `Why Custom Code Is Still Needed` 無法回答，不准直接自己寫。

## 典型例子

- 文件解析：先 MarkItDown / Docling / Unstructured，不寫 PDF parser
- Permission：先 OpenFGA / OPA / Cerbos，不寫 relationship graph evaluator
- Context Budget：吸 Codex / GraphRAG，不從零發明 compaction
- Telemetry：採 OpenTelemetry GenAI conventions，不發明 vocabulary
- Work Grouper：吸 OpenChronicle / DayTrail / OCEL，不憑感覺發明 sessionization
- Multi-Agent：Knowledge SaaS 只定 Evaluation Strategy，不造 mailbox / wake / agent process manager

## 授權

每次吸收保存 repository、URL、commit/tag、license、拿了什麼、沒拿什麼。授權不清楚先標 `REFERENCE_ONLY`。
