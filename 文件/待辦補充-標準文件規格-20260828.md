## 6. `STD-00` key frozen proposals

待review的主要裁決：

```text
OMOS-generated ID = UUIDv7
*_id = bare lowercase UUID
*_ref = typed urn:omos URI

stable source identity
= tenant + source system + source instance + entity type + native id

CloudEvents
= transport only

OpenLineage
= activity lineage only

source event ID
!= delivery ID
!= ingestion attempt ID
!= Evidence ID
!= payload digest

source version
= basis + kind + value + secondary digest

chronology
= occurred + observed + received + persisted

range
= half-open

text offset
= Unicode code point

PDF bbox
= top-left normalized [0,1], 6 decimals

digest
= raw + optional canonical + normalized

canonicality
!= lifecycle
!= source availability
!= payload retention
!= verification
!= acceptance

Object identity
= durable reference authority, not Knowledge

ObjectLink
= LinkDecisionReceipt, no permission expansion

WorkRecord
= permission-aware rebuildable projection
```

## 11. Review gate

Codex輸出必須採：

```text
VERDICT: ACCEPT | AMEND | BLOCK
```

每個Finding必須指向：

```text
exact file
exact section / field
authority impact
proposed amendment
fixture/test
```

### `ACCEPT`

仍需使用者／指定authority明確接受，才更新：

```text
STD-00 = LOCKED
STD-01 = READY_FOR_DESIGN
```

### `AMEND`

只做bounded amendment，不重寫Knowledge OS。

### `BLOCK`

只在存在以下之一時成立：

- identity collision。
- authority bypass。
- permission leak。
- chronology falsification。
- irreversible projection coupling。
- Phase-1 fixture無法表達。
- machine-readable companion無法解析。
