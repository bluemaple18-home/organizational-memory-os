# 上下文預算與檢索

## Context Budget 是架構 primitive

Context Budget 不是 prompt optimization，而是直接控制 token cost、latency、retrieval precision、context pollution 與 scalability 的產品能力。

```text
Query
→ Identity / Permission
→ Intent / Domain
→ Candidate Sources
→ Authority / Priority / Freshness
→ Context Budget
→ Bounded Retrieval
→ LLM
```

## ContextPolicy

至少包含：

- source
- scope
- authority
- priority
- freshness
- estimated_tokens
- permission
- load_policy

## Prior Art 吸收

從 OpenAI Codex / coding-agent ecosystem 吸：

- token estimation
- reserve tokens
- keep-recent window
- turn boundary preservation
- tool-call pair preservation
- compaction / summarization trigger
- large-context cutoff
- tool output limiting
- failure / retry handling

從 Microsoft GraphRAG 吸：

- token-aware context assembly
- mixed source context builder
- entity / relationship / text-unit context construction

從 Qdrant 吸：

- payload filtering
- tenant partitioning
- dense/sparse/hybrid retrieval

## 不吸收

Codex rollout/session/task/memory identity 不進 Knowledge SaaS；GraphRAG graph 不成 canonical knowledge truth；Qdrant 不成 permission authority。

## Retrieval 原則

Permission filter 必須先執行。Authorized scope 建立後才做 vector/graph/keyword retrieval。

Context Budget 可以依 SaaS Capability Level 逐步加深：

- L1：基本 top-k + token cap
- L2：hybrid + rerank + dynamic budget
- L3：authority/freshness/source routing
- L4：adaptive graph/multi-source learning retrieval

但基本 permission safety 不屬付費牆。
