# Obsidian 式關聯圖開源整合裁決

日期：2026-09-07

狀態：`P1 PRIOR ART / DECISION READY / NOT CURRENT FRONTIER / PROJECTION_ONLY`

Source baseline：`organizational-memory-os main@287f491575044751034679f63c13f1f47d81162e`

輸入：使用者提供的 Obsidian 全域關聯圖截圖；圖中已出現高密度邊線、標籤互相遮蔽、中心節點過度吸附等典型 hairball 問題。

---

## 0. 最終裁決

Obsidian 應視為產品體驗參考，不是可直接吸收的開源核心。官方授權雖允許免費個人／商業使用，但保留 App 文字、圖片與程式碼權利；不得把「免費使用」誤判成「開源可複製」。

Organizational Memory OS 的正式預設技術組合：

```text
Renderer: sigma@3.0.3
Graph model: graphology@0.26.0
Layout: graphology-layout-forceatlas2@0.10.1
Overlap cleanup: graphology-layout-noverlap@0.4.2
```

採用姿態：

- `Sigma.js + Graphology`：`ADOPT_CORE`。
- `ForceAtlas2 + Noverlap`：`ADOPT_LAYOUT`，優先以 Web Worker 執行。
- Sigma v4：tag 仍屬 beta；`WATCH_ONLY`，production 先鎖 v3.0.3。
- `Gephi Lite`：`REFERENCE_ONLY`，吸收完整 graph explorer 的 UX／測試情境，不複製 GPL-3.0 App code。
- `Cytoscape.js`、`AntV G6`：`ALTERNATIVE_ONLY`，不得與 Sigma 在第一版形成雙 renderer stack。
- `cosmos.gl`：`TRIGGER_ONLY`，只有 authorized subgraph 經 benchmark 證明 Sigma 不足，才開極大量圖形 spike。
- `Foam`、`Logseq`、`SilverBullet Object Graph`：只吸 PKM／typed-relation 探索語意；不搬它們的資料模型、儲存與產品 authority。

產品順序不變：

```text
P1-B：Reviewer / Impact Navigator（小、可解釋、權限安全）
P2：Global Knowledge Explorer（聚合、分群、漸進展開）
```

本研究不得插隊目前施工順序：

```text
STD-03 NormalizedDocument
→ Document Adapter
→ Jira Adapter
→ Permission / Retention / Deletion
→ Canonical Direct-Write Audit
→ Architecture Canvas
```

## 1. Existing project seams：不是新建 Knowledge Graph 系統

本裁決對齊現有責任：

| Existing seam | 現有裁決 | 本輪 delta |
|---|---|---|
| Projection Boundary | Graph／Vector／Chunk／Search 均可刪除重建，不能取得 Canonical authority | 封瀏覽器 renderer、layout、query contract；不增第二套 truth |
| Permission-before-Retrieval | 先身份與政策，再建立可取回空間 | 延伸為 Permission-before-Graph；聚合、degree、cluster count 也不得洩漏未授權存在性 |
| Reviewer Graph / Impact UI | `P1-B / PROJECTION_ONLY` | 收斂成第一個可交付 graph mode |
| Advanced Knowledge Graph Exploration | `P2 / Trigger` | 全域 Obsidian 式視圖延後，且只顯示聚合／bounded drill-down |
| AI Core boundary | AI Core 是 donor／producer／runtime adapter | AI Core 可提交 Evidence／Relation Proposal；不得在 AI Core 再建一套 graph authority |

正式資料流：

```text
Sources / AI Core producer
→ Raw Evidence
→ Object linking / Relation Proposal
→ Verification / Acceptance
→ Canonical Entity + Canonical Relation
→ Graph Projection Builder
→ Permission-filtered bounded subgraph
→ Sigma.js + Graphology UI
```

禁止：

```text
Markdown link / embedding similarity / LLM guess
→ direct canonical edge
```

也禁止：

```text
Graph UI drag / connect / edit
→ direct canonical mutation
```

圖上的人工新增關係若未來開放，只能形成 `RelationProposal`，再走既有 governance／acceptance／single-writer。

## 3. 為何選 Sigma.js + Graphology

### 3.1 與本產品邊界相容

Sigma 主要負責 render；Graphology 主要負責 client-side graph model 與算法。這種分工容易維持：

```text
server canonical relation != client graph object
client graph object == disposable view projection
```

Graphology graph 可由每次 authorized API response 重建；不需要將其序列化成另一個企業 truth store。

### 3.2 可直接吸收成熟互動

Sigma 已有可用的：

- WebGL render 與 camera。
- hover／click／search focus。
- node／edge reducers，用於 selection、dim、filter、style projection。
- framework-neutral integration。

Graphology 已有可用的：

- directed／undirected／mixed graph。
- graph events。
- connected components、shortest path、Louvain／Leiden 等算法。
- ForceAtlas2、Noverlap、GEXF／GraphML 等生態。

Custom delta 只保留產品獨有部分：

```text
Permission-safe query
Canonical relation vocabulary
Evidence/provenance side panel
Review / impact workflow
Lifecycle/conflict/freshness semantics
Projection invalidation
```

### 3.3 避免 Obsidian 式 hairball

使用者截圖證明「所有節點＋所有標籤＋所有邊一次上畫面」沒有足夠產品價值。正式 UI 必須以 bounded exploration 取代無界全圖：

- 預設只畫 local／review context。
- label 有獨立 budget，不等於 node count。
- 未選中／未 hover 的非鄰居降 opacity。
- 搜尋後聚焦，不只放大文字。
- 全域圖先 cluster／aggregate，再 drill down。
- degree／size 不可直接等同「重要性」。
- edge 必須 typed；`RELATED_TO` 只能是最後 fallback，且不得混淆 verified relation。

## 4. P1-B：Reviewer / Impact Navigator

第一個 graph product 不是「全公司宇宙圖」，而是審核者可完成工作的小圖。

### 4.1 Root types

```text
CandidateKnowledge
CanonicalKnowledge
Procedure
WorkRecord
Review
Decision
Object
SourceEvidence
RepositoryArtifact
```

### 4.2 Edge types

第一版只開有明確 authority 與產品價值的 edge：

```text
DERIVED_FROM
CITES
SUPPORTS
CONTRADICTS
CONFLICTS_WITH
SUPERSEDES
DEPENDS_ON
IMPACTS
VERIFIED_BY
ACCEPTED_BY
LINKED_TO_OBJECT
SAME_OBJECT
```

Embedding similarity 只能顯示為：

```text
SIMILAR_TO_PROJECTION
```

且必須與 accepted relation 視覺、filter、legend 分開。

### 4.3 Default bounds

```yaml
mode: reviewer_impact
max_depth: 2
node_limit: 300
edge_limit: 1000
label_limit: 80
layout_time_budget_ms: 1500
```

這些是安全預設，不是最終容量宣稱。超限必須回傳 `truncated: true` 與可解釋的 truncation reason；不得靜默抽樣後假裝完整。

### 4.4 必要互動

- 搜尋 entity／source／relation。
- click node：選取並開 provenance／status／freshness／permission／source anchor side panel。
- click edge：顯示 relation type、authority state、confidence、evidence refs；可跳 exact source anchor。
- hover：只強調一跳鄰居；不得顯示未授權隱藏關係的數量。
- expand one hop／collapse branch。
- path highlight：只在 authorized graph 內計算。
- filters：entity type、relation type、domain、scope、time、lifecycle、verification、conflict。
- list/table fallback：WebGL 不可用或 accessibility mode 時仍能完成 review。
- export：只可匯出目前 authorized response，並附 policy／projection/version receipt。

## 5. P2：Global Knowledge Explorer

全域圖只能在 P1-B 與安全 contract 成熟後進場。

正式形態：

```text
Authorized universe
→ server-side aggregate / community projection
→ cluster graph
→ user drill-down
→ bounded local subgraph
```

不得：

```text
tenant 全部原始 node/edge
→ browser 一次下載
→ client 再做 ACL hide
```

Global mode 預設顯示的是 domain／project／source／knowledge lifecycle cluster，不是所有 note label。cluster count、centrality、community membership 都必須在 authorization 後計算，否則會以統計值洩漏隱藏資料。

## 6. Permission-before-Graph

Graph 是最容易發生 existence leakage 的 UI。正式 gate：

```text
Identity
→ Managed Policy Floor
→ Authorized entity/relationship universe
→ bounded root expansion
→ authorized aggregation / metric
→ response serialization
→ browser renderer
```

最低 invariants：

1. 未授權 node 不回傳。
2. 指向未授權 node 的 edge 不回傳，也不得留下 dangling placeholder。
3. `degree`、cluster size、centrality、path、neighbor count 只以 authorized subgraph 計算。
4. unauthorized root 的錯誤語意不得洩漏其是否存在；依正式 permission contract 對齊 `NOT_FOUND`／policy denial。
5. Graph cache key 必須含 tenant、principal/policy scope、projection version、filter、bounds。
6. ACL／retention／deletion delta 必須使相關 node、edge、aggregate、layout cache 失效。
7. export 與 screenshot metadata 不得包含 hidden IDs／labels。
8. policy decision receipt 可被 AnswerTrace／EvaluationReceipt 引用。

## 7. Projection contract

建議邏輯責任，不代表現在建立四張 permanent table：

```text
GraphNodeProjection
GraphEdgeProjection
GraphLayoutSnapshot
GraphProjectionCheckpoint
```

### 7.1 GraphNodeProjection

必要欄位：

```yaml
node_id: opaque projection id
entity_ref: canonical entity reference
entity_type: controlled vocabulary
label: authorized display label
lifecycle_state: candidate|canonical|superseded|deleted|...
verification_state: PASS|FAIL|PARTIAL|NOT_RUN|STATIC_ONLY
freshness_state: current|stale|unknown
scope_ref: authorized scope
visual_tokens:
  size_metric: bounded product metric
  category: semantic color token
  badges: []
projection_version: ...
```

`visual_tokens` 是 UI projection，不能回寫 knowledge semantics。

### 7.2 GraphEdgeProjection

```yaml
edge_id: opaque projection id
source_node_id: ...
target_node_id: ...
relation_type: controlled vocabulary
authority_state: proposed|verified|accepted|projection_only
confidence: optional
weight: optional bounded visualization value
evidence_refs: []
first_observed_at: ...
last_observed_at: ...
projection_version: ...
```

至少一個 `evidence_ref` 或 canonical relation record 必須支撐非 projection-only edge；「LLM 覺得有關」不能成為唯一來源。

### 7.3 GraphLayoutSnapshot

```yaml
query_fingerprint: hash of authorized bounded query
layout_engine: forceatlas2
layout_version: graphology-layout-forceatlas2@0.10.1
seed: stable seed
positions: disposable map
created_at: ...
```

layout cache 只是效能與視覺穩定性資料；可刪除重建。使用者拖曳固定位置屬 `ViewPreference`，也不得變成 knowledge fact。

## 8. API draft

正式草案另見：

```text
規格/v0.1/graph-query-contract.draft.yaml
```

建議入口：

```http
POST /api/v1/graph/query
```

Request 核心：

```json
{
  "mode": "reviewer_impact",
  "roots": [{"entity_type": "CandidateKnowledge", "entity_id": "..."}],
  "depth": 2,
  "node_limit": 300,
  "edge_limit": 1000,
  "relation_types": ["DERIVED_FROM", "CONFLICTS_WITH", "DEPENDS_ON", "IMPACTS"],
  "filters": {
    "domain_ids": [],
    "scope_ids": [],
    "lifecycle_states": [],
    "time_range": null
  }
}
```

Response 必須帶：

```text
nodes
edges
truncated + truncation_reasons
policy_decision_id
projection_version
relation_vocabulary_version
layout_hint/version
generated_at
```

前端不得接受一個沒有 policy／projection receipt 的 graph payload 作 reviewer authority。

## 9. Performance / scale gate

不以 donor 行銷數字直接當產品承諾。Spike 必須用本產品 fixture：

```text
G-SMALL: 300 nodes / 1,000 edges
G-MEDIUM: 2,000 nodes / 8,000 edges
G-LARGE: 10,000 nodes / 40,000 edges
G-DENSE: high-degree reviewer/impact pathological graph
G-UNICODE: 繁中／英文／emoji／long labels
G-ACL: authorized and hidden entities mixed
```

量測：

- initial render time。
- layout worker time。
- pan/zoom frame responsiveness。
- hover/select latency。
- memory high-water mark。
- filter/update latency。
- label collision／readability。
- deterministic teardown／worker cleanup。

只有 `G-LARGE` 或實際 authorized graph 明確不過 gate，才啟動 cosmos.gl comparison。即使換 renderer，API／permission／projection contract 不變。

## 10. Acceptance / failure cases

### 10.1 Security / governance

- [ ] 未授權 entity／relation／count／path 不可由 payload、metric、cluster、tooltip 或 export 推得。
- [ ] ACL change、retention expiry、source deletion 後，projection 與 layout cache 會被失效並可驗證。
- [ ] Graph UI 不存在 direct canonical writer path。
- [ ] proposed／verified／accepted／projection-only edge 視覺與 legend 明確分離。
- [ ] edge 可追到 canonical relation 或 evidence/source anchor。

### 10.2 Boundedness / honesty

- [ ] depth、node、edge、label、time budget 均由 server enforce；client 參數不可擴權。
- [ ] truncation／partial result 明確，不宣稱完整。
- [ ] 無 source／authority 的關係不得偽裝為 accepted edge。
- [ ] global graph 不一次下載 tenant 全圖。

### 10.3 Reliability / UX

- [ ] worker start／stop／kill／route change cleanup 有測試。
- [ ] Graphology event listeners 與 Sigma renderer teardown 不 leak。
- [ ] empty、single-node、disconnected、self-loop、parallel relation、high-degree、long-label fixtures 均有測試。
- [ ] WebGL unavailable 有 list/table fallback。
- [ ] keyboard focus、reduced motion、screen-reader summary 有最低可用路徑。
- [ ] UI 可顯示 `why connected?`，答案來自 typed relation + evidence，不由臨時 LLM 猜測。

### 10.4 License / supply chain

- [ ] adopted package exact pin 與 lockfile integrity。
- [ ] MIT notices 進 third-party notices／SBOM。
- [ ] GPL／AGPL donor 只作 reference；沒有不明 code copy。
- [ ] SilverBullet standalone repo license 未封前保持 `REFERENCE_ONLY`。
