## 使用規則

每次吸收都要記錄：來源 URL、commit/tag、license、拿了什麼、沒拿什麼、對應 Existing Seam、tests/failure cases、Custom Delta。

授權不清楚時只能先列 `REFERENCE_ONLY`，不可直接複製原始碼。

### Native event mapping rule

正式吸收方式：

```text
native event
→ immutable NativeEventReceipt
→ neutral semantic mapping
→ Work transition proposal
→ existing Work lifecycle / review
```

禁止：

```text
runtime event
→ direct ACCEPTED / CLOSED
```

跨runtime共用的是：

```text
ExecutionRequest
ExecutionReceipt
NativeEventReceipt
```

不是：

```text
Provider Registry
Universal Session
Universal Task
Universal Hook FSM
```

### Four-loop裁決

| Proposal Loop | Existing authority seam |
|---|---|
| Capture | Evidence Admission／Raw Evidence／Capture Health |
| Closeout | WorkRecord／CloseoutProposal／result verification |
| Consolidation | Structure／dedup／conflict／freshness／Candidate |

四個Loop只作domain operation grouping；不得建立新的Knowledge Architecture。
