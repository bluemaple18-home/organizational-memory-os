# 4. `PMEM-00` — First bounded card

## Goal

不改任何 AI Core 檔案，只確認每一個 memory surface的真實角色與資料流。

## Exact read scope

```text
.memory/**
.founder-vault/**
```

以及只有為確認 producer／consumer必要的：

```text
memory相關 rules／skills／scripts／tests／docs references
```

不得把整個 AI Core重新架構化。

## Required outputs

每個 surface至少輸出：

```text
path
purpose
producer
consumer
identity
record shape
active／legacy／historical
truth role
canonical／candidate／evidence／projection
write path
promotion path
read／recall path
retention／deletion
source refs
known drift
```

並輸出：

```text
CURRENT
LEGACY
PROJECTION
AUTHORITY_UNRESOLVED
SAFE_TO_TRANSLATE
DO_NOT_TOUCH
```

## Required questions

1. `.memory/logs/ai_core_memories.jsonl` 是 active source log、runtime memory、或 current knowledge owner？
2. `legacy_canonical_memories.jsonl` 是否只屬歷史 archive？
3. Founder Vault哪些檔是 curated accepted memory，哪些只是 startup projection？
4. `memory-summary.md` 的 producer／refresh方式是否仍存在？
5. 哪些 memory內容被 always-load或on-demand讀取？
6. 哪些欄位可直接映射 OMOS RawEvidence／Memory Candidate？
7. 來源刪除、修正、失效目前是否能傳播？
8. 現有 promotion有沒有繞過 review／source support？

## Forbidden

- 修改 `.memory` 或 `.founder-vault`。
- 清理／刪除／搬移 legacy data。
- 建新 memory DB。
- 重寫 AI Core Work／Task／Runtime。
- 建 provider adapter。
- 安裝 Hermes／DSH。
- 建 global hook。
- 自動promotion。
- 產生不可追溯的summary覆蓋現有內容。

## Acceptance

```text
read-only evidence complete
all claims have exact path／source
no mutation
no speculative authority assignment
bounded next-card recommendations only
```
