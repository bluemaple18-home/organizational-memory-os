# 3. `EMEM-00` — Scope / Ownership / Privacy Contract

## Root question

公司提供的 PERSONAL memory 到底是：

```text
EMPLOYEE_PRIVATE
COMPANY_MANAGED_PERSONAL
SHARED_WORK_CONTEXT
```

中的哪一種？不同模式下，誰可讀、誰可刪、誰可export、離職怎麼處理？

## Required outputs

1. 三種 personal scope mode 的 exact semantics。
2. employee／manager／admin／reviewer／system actor permissions。
3. consent／notice requirements。
4. retention／legal hold／offboarding／export／delete rules。
5. source ACL → personal memory ACL inheritance。
6. promotion時的 redaction與scope widening gate。
7. negative fixtures。

## Acceptance

- `PERSONAL` 不再只是模糊名稱。
- 公司管理員不得因 admin 身分自動取得所有 personal memory內容。
- COMPANY_MANAGED_PERSONAL 的公司權利與員工權利可被 machine-readable policy表達。
- SHARED_WORK_CONTEXT 不得偷偷包含 EMPLOYEE_PRIVATE material。

## Forbidden

- DB implementation。
- Connector deployment。
- 全員自動擷取。
- AI Core memory migration。
