## 4. Required checks

### A. Axis separation

確認以下沒有混成單一enum：

```text
canonicality
lifecycle
source availability
payload retention
activity execution
verification
acceptance
```

### B. Identity

確認能分開：

```text
source-native entity ID
source-native event ID
transport delivery ID
ingestion attempt ID
Evidence ID
payload digest
source version
```

### C. Idempotency

至少用negative fixtures驗：

```text
same redelivery
redelivery payload mismatch
same source new revision
same bytes different sources
no native event id
```

### D. Chronology

確認four-clock：

```text
occurred
observed
received
persisted
```

不會讓後補Evidence偽裝成舊Answer已使用。

### E. Source Anchor

確認：

```text
PDF_REGION_V1
MARKDOWN_TEXT_V1
JIRA_CLOUD_ENTITY_SEGMENT_V1
```

都有representation digest、position selector、quote/fallback與resolution status。

### F. Jira

確認：

- numeric ID與issue key alias分離。
- webhook不被當完整history。
- 單次404不被當delete。
- permission revoked與source deleted分開。
- Cloud／Data Center adapter分開。

### G. Object Context

確認：

- Object identity不是Knowledge。
- ObjectLink suggestion與durable link分開。
- model／embedding不能高分auto-accept cross-client link。
- accepted link不擴權。
- WorkRecord mixed-scope render使用permission intersection。

### H. Projection

確認全部Projection能刪除重建，且projection ID不成Knowledge ID。
