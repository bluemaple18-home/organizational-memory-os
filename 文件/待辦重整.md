# 待辦重整

## 狀態標籤

重要 Backlog item 以以下狀態標記：

- `ALREADY_EXISTS`：現有架構/元件已涵蓋，不重做
- `PARTIAL`：方向已有但 contract / implementation 不完整
- `MISSING`：真正缺口
- `DONOR_AVAILABLE`：已有成熟先例或可吸收實作
- `CUSTOM_CODE_REQUIRED`：仍需自研產品獨有語意
- `SHOULD_NOT_ADOPT`：明確不應搬進本產品

## 高 token 研究卡改寫原則

能找到成熟 donor 的研究卡，改成 teardown / adaptation card：

- Context Budget：拆 Codex / GraphRAG engineering，只自研 ContextPolicy
- Telemetry：採 OpenTelemetry GenAI conventions，只做 mapping
- 文件解析：MarkItDown / Docling / Unstructured，不自造 parser
- Permission Engine：OpenFGA / OPA / Cerbos 做 semantic diff，不自造 graph evaluator
- Work Grouper：OpenChronicle / DayTrail / OCEL，不自造 sessionization
