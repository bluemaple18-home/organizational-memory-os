## 一、不可翻案的邊界

1. Evidence ≠ Knowledge。
2. Candidate ≠ Canonical。
3. Permission-before-Retrieval。
4. `EXECUTED != VERIFIED != ACCEPTED`。
5. Canonical Single Writer；donor/agent/model 只能提交 Proposal。
6. Vector / Graph / Chunk / Context Summary / Cache 都是 `PROJECTION_ONLY`。
7. Deterministic First；Agent / Model / Worker / Runtime 是 executor。
